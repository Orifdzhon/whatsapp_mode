# WA Fake 2.0 — всё на телефоне

Один APK. Ставится тапом, без провода и без ПК. Внутри — интерфейс на 4 таба
и мастер настройки, который сам через root включает модуль в LSPosed.

## Два режима

| | A — внедрение | B — оверлей |
|---|---|---|
| что нужно | root + LSPosed | только «Спец. возможности» |
| фейки в настоящем чате | да, пузыри внутри списка | да, рисуются поверх окна |
| архив удалённых | да | нет |
| одноразовые (view-once) | да | нет |

Оба живут в одном APK, переключаются на вкладке «Настройка».

## Экраны

- **Сообщения** — добавить фейк: `jid` или `title:Имя контакта` (или `*` — любой чат),
  текст, дата и время, список сохранённых.
- **Архив** — копии сообщений, красная метка `УДАЛЕНО`, фильтр, медиа из
  `Download/WAFakeVault/`.
- **Настройка** — проверка root/LSPosed/scope, кнопка «Включить модуль в LSPosed»,
  «Перезапустить WhatsApp», включение спец. возможностей для режима B.
- **Логи** — последние строки `WAFake` из logcat.

## Установка (после сборки APK)

1. Скачать `app-debug.apk` на телефон, открыть, разрешить установку из этого источника.
2. Открыть WA Fake.
3. Режим B сразу: «Настройка» → «Открыть настройки спец. возможностей» → включить **WA Fake**.
4. Режим A: «Настройка» → «Проверить состояние» → если root и LSPosed есть,
   нажать «Включить модуль в LSPosed» → «Перезапустить WhatsApp».
   Если модуль «ещё не виден LSPosed» — один раз открыть приложение LSPosed,
   вернуться и нажать снова.

Ни одной adb-команды.

## Сборка через GitHub Actions

`.github/workflows/build.yml`: при push в `main` собирается debug APK.

1. Создать репозиторий на GitHub, залить папку проекта.
2. Actions → workflow `build` → дождаться зелёной галочки.
3. Внизу страницы сборки — артефакт `wafake-apk`, внутри `app-debug.apk`.
4. Скачать и открыть на телефоне.

Локально SDK не нужен. Для локальной сборки — Android Studio + JDK 17.

## Проверка

| тест | что делать | ожидание |
|---|---|---|
| оверлей (B) | добавить `title:Имя`, открыть чат | пузырь над полем ввода, при прокрутке бледнеет и возвращается |
| внедрение (A) | то же при активном модуле | пузырь внутри списка, внизу, долгое нажатие убирает |
| удалённое | отправить себе → «удалить у всех» | Архив → «только удалённые» → `УДАЛЕНО`, текст цел |
| исчезающее | таймер 5 мин, дождаться | та же метка |
| одноразовое | прислать view-once, не открывать | запись `[изображение]`, «открыть медиа» работает |
| база нетронута | сравнить размер `msgstore.db` | не меняется |

## Как устроено

```
Режим A:
  RecyclerView.setAdapter   → FakeAdapterProxy (фейки в списке)
  SQLiteDatabase.insert     → MessageVault: копия сообщения + медиа
  SQLiteDatabase.update/del → метка «удалено» по key_id
  Conversation.onResume     → reconcile: чего нет в базе — удалено

Режим B:
  AccessibilityService      → заголовок чата → фейки из prefs → окно
                              TYPE_ACCESSIBILITY_OVERLAY над полем ввода
```

## Ограничения

- Оверлей: позиция фиксирована у низа экрана, при прокрутке бледнеет — это честная
  цена работы без root.
- Архив ловит только сообщения, пришедшие после установки модуля.
- В режиме A фейки добавляются в конец списка (вклинить между настоящими —
  потребовало бы записи в базу).
